# 2026-09-17 · html-slides

## 目标
用户想复刻「整页变形动画 + 流程图导航」的交互演示形态，并批量生产成许多站点，要求融合：
1. 实时标注 / 投票 / 打分并留存数据
2. HTML 本身可编辑（图片 / 文字 / 表格 / SVG）

## 结论与选型
- 用户印象中的开源项目最可能是 **impress.js**（38k star，Prezi 的 "infinite canvas" 复刻）；
  次可能为 **reveal.js 的 Auto-Animate（Keynote Magic Move 的 FLIP 实现）+ ESC 总览**，
  以及 **Slidev (44k)**、**Animotion**、**Spectacle**、**React Flow 幻灯片教程**。
  已把这几个候选连同星数、动画机制整理给用户，待其确认具体是哪一个。
- 自建方案：**共享引擎 + JSON 规格 + 构建脚本**，而不是写一个孤立页面。

## 已落地（本次新建）
- `src/flowdeck.js` + `src/flowdeck.css`：引擎。整页变形相机（translate+scale，`cubic-bezier(.22,1.28,.36,1)`
  带回弹）、流程小地图（SVG + 相机框 + 点击跳转 + 已走过/有投票/已编辑徽标）、就地编辑
  （contenteditable + 工具条：标题/正文/加粗/列表/表格/图片/SVG/分隔/撤销）、标注钉（弹出式批注、
  可在侧栏删除）、投票与评分（结果条实时更新）、房间同步与在线人数、导出单文件、hash 深链 `#节点id`。
- `decks/*.json`：两份规格（内测复盘 6 节点含分支与投票评分；选题到成稿 5 节点）。
- `scripts/build.mjs`：把 `decks/*.json` + CSS + JS 内联成 `dist/<slug>/index.html`，并产出 `dist/index.html` 入口页。
  运行：`node scripts/build.mjs`。
- 同步层当前只有 **BroadcastChannel**（同浏览器多窗口/多标签真实同步，含 hello/here 心跳做在线人数）；
  WebSocket / Yjs 服务端**未实现**，只预留了同一套消息协议（`{t:'vote'|'note:add'|'note:del'|'poll:reset'}`）。

## 踩坑记录（重要，下次直接避开）
1. **并行编辑同一文件会丢改动**：三个 Edit 同时发到一个文件，其中一处（新增 var ASSETS）静默丢失，
   导致导出时报 `ASSETS is not defined`。同一文件的多处修改必须串行。
2. **改写 document.body.innerHTML 会删掉自身 `<script>` 标签**，之后再也拿不到引擎源码，
   导出单文件必然失败。必须在改写前把自身的 `style/script[data-flowdeck]` 文本抓进变量。
3. **hash 深链会让自动化测试产生误判**：刷新后落到 `#n3`，测试却假设当前是 n2，
   于是"编辑没生效""插入覆盖了原文"都是假象。测试脚本必须动态读取当前节点。
4. **`document.execCommand` 的返回值依赖焦点元素**：对着非 contenteditable 的元素 focus 后调用必然返回 false，
   不要据此断定"execCommand 不可用"。
5. **无限 CSS 动画会让自动化点击不稳定**（Playwright 等待元素静止，可能重复触发）：
   把呼吸/浮动动画放到按钮内部元素上，按钮自身盒子保持稳定。
6. 长按 `_` 类：`stagger()` 写入的 `--i` 内联变量会混进保存的 HTML，保存前要清理
   （已加 `cleanHTML()`）。
